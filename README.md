# ❤️ Heart Health Predictor

### Machine Learning Based Heart Disease Risk Prediction System

Heart Health Predictor is a Machine Learning web application that estimates the likelihood of heart disease based on various clinical and cardiovascular health parameters.

The application uses a trained **Random Forest Classification** model and provides an easy-to-use **Streamlit web interface** where users can enter patient information and receive a prediction along with the estimated probability of heart disease.

---

## 🚀 Project Overview

Heart disease is one of the major health concerns worldwide. Early identification of potential risk factors can help in taking appropriate preventive measures.

This project demonstrates how Machine Learning can be applied to healthcare-related data to build a predictive system.

The system accepts patient information such as age, sex, chest pain type, blood pressure, cholesterol, maximum heart rate, and other clinical parameters. The trained Random Forest model processes these parameters and predicts whether the patient is likely to have heart disease.

> ⚠️ **Disclaimer:** This project is intended for academic and educational purposes only. It is not a medical diagnostic system and should not be used as a substitute for professional medical advice.
